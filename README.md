# 萌遇 MoGotcha - 技术支持 / Technical Support

## 中文

欢迎来到 **萌遇 MoGotcha** 的技术支持页面！

**萌遇** 是一款拍摄对象收集 App：遇见想记录的它（猫、狗、昆虫，或你自建类别的任何东西）→ 拍照/记录地点与时间 → 生成专属缘分养成卡 → 收集进你的图鉴。所有照片与位置数据都只保存在你的设备本机，不会上传到任何服务器。

### 如何反馈问题

1. 点击上方的 [**Issues**](../../issues) 标签页
2. 点击 "**New Issue**" 按钮创建新问题
3. 填写问题描述并提交

TestFlight 测试者也可以直接在 TestFlight App 内对当前测试版本提交截图反馈，两种渠道都会被处理。

### 反馈内容建议包含

- 📱 设备型号和系统版本（如：iPhone 17, iOS 26.0）
- 📝 问题的详细描述
- 🖼️ 截图或录屏（如果可能）
- 🔄 复现步骤

## English

Welcome to **MoGotcha** technical support!

**MoGotcha** is a collection app for the subjects you photograph: meet something worth remembering (a cat, a dog, an insect — or anything in a category you create yourself) → take a photo / record the location and time → generate a unique bond card → collect it into your dex. All photo and location data is stored only on your own device — nothing is ever uploaded to any server.

### How to Report Issues

1. Click the [**Issues**](../../issues) tab above
2. Click "**New Issue**" to create a new report
3. Fill in the problem description and submit

TestFlight testers can also submit screenshot feedback directly within the TestFlight app for the current build — both channels are monitored.

### Please Include

- 📱 Device model and OS version (e.g., iPhone 17, iOS 26.0)
- 📝 Detailed problem description
- 🖼️ Screenshots or screen recordings (if possible)
- 🔄 Steps to reproduce
